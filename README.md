# LLI Grammar Mastery

Grammar Mastery Checklists and interactive Quick Checks for CEFR levels A1–C2, by LLI · Lexilink Ideation.

**Live site:** https://lexilink-ideation.github.io/LLI-Grammar-Mastery/

## Files

| File | What it is |
|---|---|
| `index.html` | Home page: all six levels, links to Quick Checks, checklist downloads |
| `a1.html`, `a2.html` | Interactive Quick Checks: point checks, unit reviews, level diagnostic |
| `LLI_Grammar_Mastery_Checklist_A1.docx` … `C2.docx` | Editable Word checklists |

## Turning on the website (one time)

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, folder **/ (root)** → Save.

## Updating

The pages are generated from question banks and templates, so don't edit the .html files by hand. To add a level (for example `b1.html`) or change questions, generate new files and upload them here; uploading a file with the same name replaces the old one.
